# Mini Search Engine in C++

A simple search engine built using C++ that searches text documents based on user-provided keywords and displays relevant results.

## Features
- Search for keywords across text documents
- Read documents from files
- Display matching document names
- Rank search results by relevance
- Simple command-line interface

## Technologies Used
- C++
- STL (Standard Template Library)
- File Handling
- Data Structures and Algorithms

## Project Structure
```text
Mini-Search-Engine/
├── src/
│   └── main.cpp
├── data/
├── README.md
├── .gitignore
└── LICENSE
```

## How to Run

Compile using a C++ compiler:

```bash
g++ src/main.cpp -o search
```

Run on Windows:

```bash
search.exe
```
